How to run a block

  1. Use Chrome or Edge. Connect the projector as an extended display (not mirrored).
  2. Click Presenter for the block. Then click Open audience in the presenter view. If the browser asks to manage windows, allow it: the audience window then opens on the projector.
  3. Click once on the audience window to make it fullscreen (or drag it to the projector first, then click).
  4. Click back on the presenter window so the clicker drives it. Right / PageDown = next, Left / PageUp = back, B = black screen.
  5. Decks keep loading in the background for a few seconds after opening. The running order marks them while they load.

Single screen fallback: open Audience only and drive it with the clicker directly.
